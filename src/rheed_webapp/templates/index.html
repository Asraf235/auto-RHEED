Streak Profile (Auto)

How it works
Draw a strip ROI spanning the specular spot and both first-order streaks. Background-subtracts the row-summed profile, finds all three peaks, and averages the two specular↔first-order distances — then tracks that automatically across every frame instead of clicking each one by hand.
What this measures
Also measure the specular streak's width each frame and convert it to an in-plane coherence length (terrace/domain size). Narrowing = smoother / more ordered surface; broadening = roughening. Opens an L(t) window after tracking.

Auto RHEED

A browser-based analysis suite for Reflection High-Energy Electron Diffraction (RHEED) data. Designed for thin-film growth researchers, Auto RHEED combines real-time frame visualization, quantitative calibration, angle-of-incidence tracking, and in-plane lattice parameter measurement in a single interactive interface.

Developed at Oak Ridge National Laboratory (ORNL) · 2025

Tabs

  • Calibration: mark direct beam, shadow edge, specular spot and camera edges on a still/mean frame; compute pixel scale (cm/px) and angle of incidence α; save annotated image + JSON
  • Acquisition: placeholder for live-acquisition features (planned)
  • Growth Analysis: the main workspace: load a growth/rocking video, calibrate, and run all the per-frame analyses below on a shared dataset
  • Library: a persistent reference gallery of RHEED patterns for different substrates; add images tagged with material, surface, zone axis, energy, and notes (.img/.tif/.png decoded to PNG), filter, and enlarge
  • About: this page

Capabilities (Growth Analysis)

  • Multi-format loading: .h5 (HDF5), .mp4/.avi/.mov/.mkv (video), .npy, single images, or a folder of per-frame images stacked into one video
  • Frame viewer: scrub, play (spacebar / ◀ ▶), zoom, rotate; per-frame or whole-video auto-contrast; save a frame (PNG) or all frames (ZIP)
  • Colormaps: gradient-swatch picker including the perceptually-uniform Viridis / Plasma / Inferno / Magma and the colorblind-safe Cividis, plus Thermal, Rainbow, Marine, Cyan–Magenta, and Grayscale
  • Substrate Calibration: from a known substrate + zone axis, compute pixel scale via d = λL/Δx (relativistic electron wavelength). The reference d can come from the built-in table, the Materials Project database (your own free API key), or a custom value you type in
  • Frame Calibration: per-frame 5-point calibration giving α, scale, and shadow edge for peak tracking
  • ROI Tool & Intensity vs Time: draw circle/rect/line ROIs; plot each ROI's intensity in its own stacked subplot with independent show/EMA-smoothing/α and per-ROI or combined CSV export; linear or log Y
  • FFT / Growth Rate: per-ROI Fourier analysis of the intensity oscillations (one resizable window per ROI): detrends (EMA / linear / mean), reports the dominant frequency f₀ (= ML/s), period (s/ML), and deposition rate (Å/s) using a growth-direction layer thickness derived from the substrate (or set manually)
  • Peak Tracking & α(t): track specular and/or direct-beam position frame-by-frame; compute α(t) by two methods; sine-fit; rocking curve (specular intensity vs α)
  • Streak Spacing: click two diffraction streaks → in-plane lattice parameter d; compare against the materials database; drag markers to refine
  • Film Streak Tracking — dfilm(t): measure film streak spacing frame-by-frame and build d(t), with EMA time-series smoothing and averaged-CSV export
  • Streak Profile (Auto): draw one strip ROI; background-subtract the row-summed profile (ALS / rolling-ball / polynomial / moving-min / none), auto-detect the specular + first-order peaks, and track d(t) across every frame
  • FWHM & coherence length: from the same strip profile, measure the specular streak's width each frame (selectable: kSA-style Gaussian fit, FWHM = 2.3548·σ, or a raw half-max read-off) and convert it through the d-spacing calibration into an in-plane coherence length (terrace/domain size, Å). Stacked FWHM(t) / L(t) panels that evolve per frame as the video plays, with EMA smoothing and CSV export (both methods); narrowing streaks = smoother / more ordered surface, broadening = roughening

Materials reference & d-spacing sources

  • Built-in table: ~50 common oxide, semiconductor, and hexagonal substrates with standard room-temperature lattice constants. These are literature/textbook values (not pulled from any database) — see materials_database.xlsx in the project root for every value plus a per-entry source/uncertainty note
  • Materials Project: optional live lookup against materialsproject.org using each user's own free personal API key. DFT-relaxed values (typically ~1% large); verify the conventional cell before citing. Setup: create a free account at materialsproject.org and copy your personal API key from the dashboard.
  • Custom: type your own in-plane d (Å) directly when you trust a specific reference

File formats

  • .h5 / HDF5: datasets frames (N × H × W) and optional timestamps (N,)
  • .mp4 / .avi / .mov / .mkv: standard video, decoded to grayscale via OpenCV
  • .npy: NumPy 3-D array (N × H × W)
  • .tif / .png / .jpg / .bmp / .img: single calibration images, or drop a whole folder/selection of per-frame images to stack into a video

Backend stack

  • Flask: lightweight Python web server; all analysis routes exposed as REST endpoints
  • NumPy: array operations, argmax, weighted centroid, FFT
  • OpenCV (cv2): video decoding, image reading (incl. 16-bit TIF), colormap rendering
  • h5py: HDF5 file I/O
  • SciPy: curve_fit for sine-wave fitting, find_peaks, map_coordinates

Frontend stack

  • Vanilla JS: no framework; all UI state managed in plain JS
  • HTML5 Canvas: ROI drawing, calibration overlays, resize handles
  • Plotly.js: interactive α(t) chart, rocking curve scatter plot, intensity vs time

Keyboard & interaction tips

  • Spacebar play/pause; ◀ ▶ arrow keys step frames
  • Drag the left sidebar edge to resize it
  • Press Esc to cancel streak-click or calibration mode
  • Drag ROI handles (corner/edge dots) to resize any ROI; right-click an ROI or the strip box to delete it
  • Drag S1/S2 streak markers after placing them to refine the measurement
  • All floating windows (α(t), d(t), Intensity, Streak Profile, FWHM & Coherence, FFT, and the Growth Frame Viewer) are draggable and resizable; click any window to bring it to the front
  • Every chart window (Streak Profile, FWHM & Coherence, d(t), Intensity vs Time, and each FFT window) has a PNG button that lets you set the font size and output DPI (default 600, embedded in the PNG) before saving — all chart fonts (axis titles, ticks, legend) scale together for publication-ready figures. The data windows also export CSV: including the Streak Profile (raw / baseline / subtracted columns for the current frame)
  • The Growth Frame Viewer has its own 🖼 export that saves the frame plus its overlays (ROIs, streak markers, peak guides) as a high-resolution PNG; before saving you can set the overlay label font size and the output resolution (default 600 DPI), which is embedded in the PNG for publication figures
  • Each ROI opens its own independent FFT window; the Library tab keeps a persistent reference gallery of patterns by substrate

Desktop shortcut

Add an Auto RHEED icon to your Desktop that launches the app and opens it in your browser — no need to run any commands. (Windows only.)
